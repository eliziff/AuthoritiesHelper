Authorities is a local application for Microsoft Edge or Google Chrome.

Double-click Start Authorities.cmd. The launcher starts the bundled runtime on
127.0.0.1:32147 and opens Authorities in its own browser window. Double-click Stop
Authorities.cmd when you want to stop the local runtime.

The application does not require an account or install a browser. Keep this
folder together; its runtime, assets, and licences are self-contained.
